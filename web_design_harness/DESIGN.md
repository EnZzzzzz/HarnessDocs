# Design Harness 设计规范

状态：v0.1，首轮两页设计基线。范围仅为独立项目 `web_design_harness/`。

## 设计方向

以「设计研究刊物」组织阅读，以「设计师工作台」展示过程。暖白纸面、墨色大字、朱红批注构成主要识别；蓝色表示选中与修订。先提出一个具体问题，再展示推敲过程，最后留下可讨论的判断。

首页像一期研究刊物，工作台像翻到刊物里的案例折页。共享品牌、字体、间距和导航，内容布局根据叙事变化。避免渐变大字、玻璃卡片、无目的装饰图、整页仪表盘及泛化的营销文案。

## AppShell

`app/layout.tsx` → `AppShell` → `SiteNav` + `ChapterNav` + `main` + 页脚。

- 顶栏：76px 高、暖白不透明底、底部细线；左侧 DH 方印与站名，右侧两个真实路由和本期标识。
- 桌面框架：左栏 208px，内容区自适应；全站最大宽度 1600px，居中。左栏展示刊期、两个章节入口和本期研究问题。
- 左栏在 1024px 及以上吸顶；内容页保持自然滚动。主内容内边距桌面 48px，平板 28px，手机 20px。
- 小于 1024px 隐藏左栏，顶栏保留两个章节入口；小于 640px 隐藏品牌英文副标题和刊期，导航仍可直接使用，不增加抽屉操作。
- `/` 为研究概览；`/workbench` 为过程研讨。导航通过 `aria-current="page"` 明确当前位置。
- 提供跳转到正文的键盘链接；每页一个 h1；所有操作使用语义化链接或按钮。
- 页脚为研究状态与上下页入口。AppShell 不承载案例切换状态。

| background | #f7f5ef | 全局暖白纸面 |
| foreground | #242521 | 标题与正文 |
| muted foreground | #72736b | 辅助信息，避免用于小字号正文 |
| border | #deded4 | 分栏、分隔线、稿件边框 |
| primary | #b83d2b | 主要入口、章节编号、编辑批注 |
| primary foreground | #ffffff | 主要按钮文字 |

shadcn/ui 使用 CSS 变量映射主题。业务组件使用全局语义类和设计变量，避免每页建立独立配色。圆角以 4–8px 为主；阴影只用于工作台内的纸张层次。

## 字体与节奏

- UI 和正文使用系统无衬线：Arial、PingFang SC、Microsoft YaHei；无需联网加载字体。
- 中文展示标题使用 Songti SC、STSong、SimSun、serif；英文展示标题用 Georgia，保留编辑刊物的厚重气质。
- 首页 h1：桌面 clamp 48–76px，手机 44px；文章页 h1：clamp 36–56px。
- 正文 15–16px，行高 1.8；说明 12–13px，行高至少 1.6；英文眉题 10–11px、适度字距。
- 间距按 4px 系列，主要使用 8 / 12 / 16 / 24 / 32 / 48 / 64。章节靠留白和细线分隔，不把所有文字装进卡片。

## 两页的内容职责

### 01 研究概览

眉题 → 大标题「让设计，成为可以推敲的过程。」→ 简短问题说明 → 工作台入口。右侧以代码原生稿件与批注展示核心循环，不用概念装饰图替代内容。下方以三列展开「带着什么开始 / 怎样留下判断 / 下次如何更好」，最后进入本期研讨。

### 02 过程研讨

返回入口 → 研究问题标题 → 示意案例说明 → 版本切换工作台 → 本轮发现 → 下一步讨论。版本按钮同时更新稿件布局、评审批注和下方判断说明；显示批注开关只控制批注显隐。示意内容须明确标注，不使用伪造评测分数或真实实验结论。

## 组件与交互

- 基础按钮使用 shadcn/ui Base UI Button，源码位于 `components/ui/button.tsx`，通过 `components.json` 管理后续扩展。
- 路由跳转使用 Next Link；普通按钮用 Button，不能把链接嵌进按钮。
- `DesignDraft` 负责可复用的示意稿件；`Workbench` 负责三阶段状态；`AppShell` 负责布局；导航独立为小型客户端组件。
- 所有可操作元素提供清晰的焦点环，触控目标至少 44px。版本按钮使用 `aria-pressed`；批注开关有文字标签和状态。
- 动效仅用 160–220ms 的颜色、边框和透明度过渡。响应 `prefers-reduced-motion`，不使用持续漂浮、视差或滚动劫持。
- 首版内容为静态数据，无登录、后端、持久化或虚构的保存操作。

## 技术边界与验收

Next.js App Router + React + TypeScript + Tailwind CSS v4 + shadcn/ui。独立 package.json、pnpm 锁文件和端口 9358，不从兄弟项目导入运行时文件。

页面默认服务端组件；导航与工作台是小型客户端交互边界。无重型动画与图表依赖。无远程字体或远程图片依赖。

验收：两路由可直接打开与互相跳转；生产构建及类型检查通过；320px 起布局单列且无固定宽画布溢出；版本与批注可用键盘操作；内容不伪装为真实研究结果。
