# 用例与数据集管理

[返回规格总览](../spec.md)

## 用例与数据集

Case 至少包含：标题、任务文本、标签、输入文件、初始项目、预期行为、执行约束。

- 初始状态支持空项目、项目模板或上传的项目快照。
- 前端用例可以附带参考图、交互步骤、视口配置和启动说明。
- Case 修改后形成新版本，已提交实验继续引用原版本。
- Dataset 支持添加、移除、筛选用例；保存版本时固定所含用例版本。
- 支持基础文件上传、下载以及用例批量导入导出；具体交换格式在技术设计中确定。
- 评分所需参考答案或隐藏检查材料与 Agent 输入分开存放，默认不注入执行目录。

## 产物采集约定

Case 可以配置产物采集路径、排除项和补充采集规则；保存后随 Case 版本固定。未配置时使用平台内置的前端采集约定。

- 前端任务默认以 `project/` 为源码采集范围，排除依赖、缓存和凭据文件。
- 截图、检查报告等由评测器生成，并登记为本次 Run 的证据。
- Agent 可以通过约定接口声明额外产物的位置；Runner 校验其属于允许的采集范围后再收集。
- 平台不依赖 Agent 自行判断全部最终成果，也不根据 Agent 的完成声明直接判定任务达标。
- 用例约定采集什么；Benchmark 约定评分需要什么证据；实验的同步策略决定上传哪些已采集文件。

首版内置前端项目的采集约定，不要求统一抽象所有类型的 Agent 输出。具体配置格式在技术设计中确定。
