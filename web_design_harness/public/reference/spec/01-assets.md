# 账号与能力资产管理

[返回规格总览](../spec.md)

## 账号与云端资产

- 用户可以通过账号密码登录、退出，访问本人资产及历史记录。
- 资产至少包含名称、说明、标签、创建时间和更新时间。
- 支持按名称、类型、标签检索资产。
- 云端持久化资产元数据、版本快照和已上传文件；本地缓存丢失后可以重新下载。
- 已被历史执行引用的版本不可原地修改或直接删除；资产可归档并保留历史引用。
- 首版账号创建方式可采用管理员初始化，公开注册和密码找回流程待定。

## 能力版本树

- Skill、Prompt 和 Harness 独立管理版本，可以组合运行。
- 创建版本时保存完整文件快照、内容摘要、修改说明和父版本 ID。
- 已保存版本不可变，修改内容必须创建新版本；未保存的编辑内容视为草稿。
- MVP 每个版本最多一个父节点，允许从任意历史节点派生多个子节点。
- 树节点展示版本名称、标签、创建时间、修改摘要及关联评测入口。
- 支持文本差异比较；二进制文件至少展示新增、删除或变更。
- 默认版本是可调整的指针，调整它不影响已提交实验的版本引用。
- 版本树是产品层的派生关系，不要求采用 Git 作为底层存储。
