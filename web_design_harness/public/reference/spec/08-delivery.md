# 页面、验收与实施计划

[返回规格总览](../spec.md)

## 页面范围

1. 登录页。
2. 资产列表与详情：Skill、Prompt、Harness，包含编辑、版本树和差异视图。
3. 用例与数据集：任务编辑、输入管理、集合维护。
4. Benchmark：用例组成、评分配置和历史版本。
5. 新建实验：版本组合、Runner、模型和执行参数。
6. 实验详情与 Run 详情：进度、日志、预览入口、产物和评分。
7. 实验对比：配置差异、各用例分数及产物对照。
8. Runner 管理：绑定状态、能力、在线状态和任务。

首版可在同一页面中合并相关功能，不要求每项独立导航。

## MVP 验收标准

| 编号 | 场景 | 验收结果 |
| --- | --- | --- |
| A01 | 登录与权限 | 未登录不能访问资产；账号 A 无法读取账号 B 的文件或执行记录 |
| A02 | 能力版本派生 | 从同一版本创建两个子版本，树上可见关系，可查看内容差异 |
| A03 | 固定配置 | 提交实验后修改默认版本及用例内容，原实验仍引用提交时快照 |
| A04 | 独立运行 | 同一用例执行两次产生不同 Run ID 和目录，文件与项目端口不互相覆盖 |
| A05 | 前端产物 | 一个示例 HTML 或 React 任务可执行、本地预览，默认同步截图和报告；选择完整归档后可下载源码 |
| A06 | 批量评测 | 至少三个用例组成 Benchmark，运行后可查看逐项结果和完成数量 |
| A07 | 故障与评分 | 构建失败及评测器故障可区分，缺失评分不被静默当作有效成绩 |
| A08 | 实验对比 | 两个实验可按相同用例版本比较分数，查看对应截图和配置差异 |
| A09 | 中断上传 | 暂时断网后结果保留在本地，重连可补传且不生成重复记录 |
| A10 | 取消与超时 | 可终止运行中的任务并回收所管理进程，保留已有日志 |
| A11 | DeepSeekHarness 集成 | 使用真实 DeepSeekHarness 跑通执行与评测闭环，记录底座版本，不支持的能力配置有明确错误 |
| A12 | 云端持久化 | 选择完整归档且成功后清理对应本地 Workspace，仍可从云端查看记录并下载已归档文件 |
| A13 | 逐任务自动同步 | 一批任务中首个 Run 结束即自动入队上传，后续 Run 可继续执行，无需手动同步或子 Agent |
| A14 | 策略与可用性 | 默认仅上传记录与指定证据，源码标注仅本地；「完整归档」可追加上传仍存在的源码 |
| A15 | 上传队列恢复 | 上传期间重启 Runner，重启后继续未完成项，云端不出现重复产物 |
| A16 | 固定产物快照 | 上传入队后修改工作目录，不改变已入队文件内容及其摘要；评分可定位受评快照 |
| A17 | 失败及人工评分 | 失败、取消、超时仍同步已有记录；等待人工评分不阻止已有证据同步 |
| A18 | 部分同步与清理 | 单个文件上传失败不改变执行结论；仅记录同步成功不能显示完整归档，清理前展示仅本地材料 |


## 实施阶段

1. **数据与版本基础**：认证、资产、用例、数据集、Benchmark、版本快照及文件存储。
2. **本地执行闭环**：Runner、DeepSeekHarness 集成、任务状态、Workspace、日志及取消。
3. **前端产物与评分**：预览、截图、采集快照、后台同步队列、可选完整归档、基础评测及人工评分。
4. **迭代对比**：批量实验、版本树关联、结果对比及失败重跑。
5. **后续扩展**：浏览器及模型评测、多 Runner、强隔离和自动迭代控制器。

前四阶段共同构成 MVP；每阶段应有可演示的实际数据流。

## 待确认事项

以下不阻止需求整理，但会影响实现选型：

- DeepSeekHarness 的代码来源、目标版本、实际调用方式和本地授权方式。
- 云端部署环境、存储服务、技术栈及首个支持的本地操作系统。
- Skill、Prompt、Harness 现有文件格式，以及是否需要同步 Git 仓库。
- 现有用例、数据集和 Benchmark 的规模、格式与导入要求。
- 首批前端任务采用哪些启动约定、浏览器检查和视觉评分方法。
- 是否需要在非执行设备访问实时预览，或云端托管历史项目。
- 账号初始化方式、存储配额、产物保留期限及永久删除流程。
- 后续 RSI 是否自动提出修改、执行实验，以及是否允许自动晋升版本；若需要，应另行定义预算、停止条件和晋升规则。
