# evaluator-learning-loop-v2

风格参考：`web/public/outline/universal-harness-editorial.png`。

用途：Harness Docs 评测体系章节配图，3:2 横向科技编辑部手绘插画。

主题：评测 Agent 判别训练快照，与设计师后置标注核对，将错漏归纳成可执行准则；只有准则能够穿过隔离门，再由干净 Agent 在未见过、含对抗样例的验证快照上盲测。未达标沿红色管道回到归纳阶段，达标后沿绿色出口进入版本化准则档案。

构图：左侧为训练循环装置，输入多条带蓝色轨迹线、页面状态和最终产物的快照卷轴；红笔标注纸作为标准答案进入比对装置，随后由漏斗收敛为一张准则卡。中央用黑黄隔离墙强调“只传准则”，个案答案被挡在墙外。右侧为独立的验证装置，输入新的绿色轨迹卷轴和对抗样例，经仪表盘判断准确率与排序能力。红色粗管形成清晰的失败回路，绿色箭头连接版本档案。

风格：精细铅笔与针管笔线稿，半透明水彩晕染，略带俯视的轴测工程图；冷白纸张纹理，低饱和石墨灰、雾霾蓝、靛蓝，少量青绿和红色批注。大面积留白，边缘散落浅淡工程草图。

约束：不用规整 SaaS 方框流程图；不放标题、大段文字、品牌 logo 或水印；完整循环和中央准则隔离机制在缩小后仍须一眼可读。

标注版在不改变原图结构的前提下增加八个手写短标签：训练快照、设计师标注、判别与核对、归纳准则、只传准则、新批盲测、未达标、准则入库；另在隔离墙左侧加入红色小字“答案止步”。每个标签用细虚线唯一指向对应装置。
